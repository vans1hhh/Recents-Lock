# Recents Lock (LSPosed module)

Build: open this folder in Android Studio (it will generate the Gradle wrapper), then Build > Build APK.

Use:
1. Install the APK.
2. LSPosed > Modules > Recents Lock > enable, and tick **System Framework** in scope.
3. Reboot (needed - the hook lives in system_server).
4. Open Recents Lock and tick the apps you want locked.

Changes to the list apply immediately, no reboot needed after the first one.
